# WhatsApp Chat Viewer

A single-file viewer for exported WhatsApp chats. Open it in a browser, drop in your export (`.zip`, `.txt` or `.html`) and read the chat in a WhatsApp-style interface.

## Features
- Your messages on the right, the other person's on the left; the contact name from the zip file name is shown in the header
- Photos, videos, GIFs, stickers, voice notes (with a player) and documents shown in chat order
- Android and iPhone export formats
- Search, date separators, and 5 themes (Classic, Dark, Ocean, Rose, Violet)

## Privacy
Everything runs locally in your browser. Chat files are never uploaded to any server.
Do not commit your exported chats to this repository.

## Use
Open `index.html` directly, or host it with GitHub Pages.
Voice notes are `.opus` files, which play in Chrome and Edge.
